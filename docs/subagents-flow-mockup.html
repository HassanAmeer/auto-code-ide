STATE-DRIVEN RENDER RULE
status === "running" → ⟳ cyan spinner + Stop ■
status === "completed" → ✓ emerald tick (may show briefly)
status === "failed"   → ○ rose alert + badge
status === "cancelled" → ⊘ muted cancel

silent, no 'COMPLETED' label
WHY IT WORKS
  • Project scoping → card sirf is project ke agents dikhata hai, wo 'other project' ka queue nahi.
  • 90 s freshness → card 90s se purane completed rows khud clear karta hai → "No active subagents" state wapas aata hai.
  • Trim + title|role dedupe → 8 wali pileup nahi, sirf 4 unique workers shown.
  • Stop button → ek click se run cancel; ✓ rose on hover to prevent accidents.
