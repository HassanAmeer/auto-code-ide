Har state — ek nazar mein
idle Koi task nahi. Khali card, sirf "Watchdog" title.
watching Task split ho raha hai, workers assign ho rahe hain.
reviewing Sab workers ke output parallel review — no build.
building Merged workspace par ek hi `pnpm build`.
testing Ek hi `pnpm test` suite. Fail → repair sub-agent.
verified Sab clean — green border, final verdict.
failed Build/test repair ke baad bhi fail — red border.
cancelled Stop dabaya — workers abort, rows "cancelled".
Card ke andar kya hota hai — legend
spinners / active pill (cyan) review / self-heal (violet) build / test running (amber) build ✓ / test ✓ / verified (green) ✗ / failed / Stop button (red)
Har worker row: icon (spin / ✓ / ✗) · role · model · file count · build badge (✓ / ✗ / … / skipped) · test badge (✓ / ✗ / … / no tests). Review note tooltip mein, 🛠 self-heal count niche, Stop button upar right.
